# llm-translation-lab

This is a casual repository for tracking our progress, focused on translation using large language models (LLMs). The main themes are multilingual translation (starting with Chinese), simplification into "simple language", and analyzing differences in style, quality, and completeness of translations. SAIA cloud platform: https://docs.hpc.gwdg.de/services/saia/index.html
Our first task is to send a set of example Chinese sentences (provided during the course) to three different models using a simple API call, either via command line or a small Python script. We'll store the outputs, then compare the resulting translations. The tasks are tracked on the Issues.
More tasks and comparisons will follow as we go.
